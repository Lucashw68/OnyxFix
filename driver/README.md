# Official driver input directory

Place your legally obtained, extracted official Mackie Onyx-i driver files here.
This directory is ignored except for its instructions.

Required:

- `OnyxFireWire.inf`
- `OnyxFireWire.sys`
- `OnyxFireWireAudio.sys`
- `OnyxFireWireMidi.sys`

Optional: `OnyxFireWire.cat`, `OnyxFireWireAsio.dll`, `OnyxFireWire.exe`, and
`cpl.defs`. The toolkit does not download, supply, or redistribute any of them.
Do not use files from an unknown source. Validation detects obvious mismatches but
cannot prove provenance or safety.
